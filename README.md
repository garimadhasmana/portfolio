## 🚀 How to publish (step by step, no coding needed)

1. Go to **github.com** → sign in → click the **+** → **New repository**
2. Name it exactly: `YOUR-USERNAME.github.io` (e.g. `garimadhasmana.github.io`)
3. Set to **Public**, click **Create repository**
4. Click **uploading an existing file** (or drag files into the browser)
5. Upload ALL files from this folder — including `index.html`, `style.css`, `script.js`, `ai-creatives.html`, and the `images/` folder (with your images inside)
6. Click **Commit changes**
7. Go to **Settings → Pages → Source → Deploy from branch (main)**
8. Wait ~2 minutes — your site is live!

## ✏️ How to update text (no code)

1. Click `index.html` on GitHub
2. Click the pencil ✏️ icon (top right)
3. Use **Ctrl+F** to find the text you want to change
4. Edit it directly in the browser
5. Scroll down → **Commit changes**

---

## 📎 How to add your Google Slides / Canva decks

1. Open your presentation in Google Slides
2. File → Share → Publish to web → Embed → Copy the `<iframe>` src URL
3. In `index.html`, find `YOUR_DECK_ID` and replace with your URL
4. Commit — done!

---

## 🗓️ How to add your Calendly booking link

1. Sign up free at calendly.com
2. Copy your personal link (e.g. `https://calendly.com/garima-dhasmana`)
3. In `index.html`, find `https://calendly.com` and replace with your full link
4. Commit!

## 📌 Pinterest & Etsy links

In `index.html`, find:
- `https://www.pinterest.com/YOUR_HANDLE` → replace with your Pinterest URL
- `https://www.etsy.com/shop/YOUR_SHOP` → replace with your Etsy shop URL
